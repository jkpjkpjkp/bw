PERSON - first name - last name - middle name - nickname - birthday - deathday(42BC if still alive)
    note: can leave null
          if date inaccurate fill in best approximate and leave default
              e.g. "Jesus - Christ - 01/Jan/0000"

person - book
    note: the book MUST be (co-)AUTHORED by this person. with the only exception of a biography where the person deeply interacts with the author.

person - profession
    note: should be the tightest fit(s) in `profession` tree

person - creation
    e.g. "Steve Wozniak - Apple II"
    note: a company is also a creation. e.g. "Tim Watson - Walmart"
